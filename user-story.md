# User Stories

Use the format: As a [type of user], I want [goal] so that [benefit].

1. As a visitor, I want to browse available gifts so that I can find useful items.
2. As a visitor, I want to view gift details so that I can decide whether an item suits me.
3. As a visitor, I want to search by keyword so that I can find a specific gift.
4. As a visitor, I want to filter gifts by category so that I can narrow the results.
5. As a new user, I want to register so that I can create an account.
6. As a registered user, I want to log in so that I can access account features.
7. As a user, I want to log out so that my account remains secure.
8. As a donor, I want to list a gift so that someone else can reuse it.
9. As a user, I want to view the landing page so that I understand the purpose of GiftLink.
10. As a user, I want to see sentiment feedback so that I can understand the tone of a message.
